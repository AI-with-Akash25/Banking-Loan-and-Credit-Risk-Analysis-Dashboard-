# 🏦 Banking Loan & Credit Risk Analysis

An interactive **Power BI dashboard** for analyzing loan applications,
customer profiles, loan performance, credit risk, repayment patterns,
and financial insights using banking data.

## 🔍 Key Features

- Loan application analysis
- Approved and rejected loan analysis
- Credit risk analysis
- Customer profile analysis
- Loan amount analysis
- Loan type comparison
- Risk-level analysis
- Employment type analysis
- Interactive slicers and filters
- KPI cards and DAX measures
- Interactive Power BI page navigation
